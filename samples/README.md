# 시연용 샘플 공시 파일

앱의 탐지율·오탐률·우선순위를 재기 위한 **가짜** 공시 파일이다. 기관 이름과 수치는 모두 지어낸 것이며 실제 기관과 무관하다. 설계는 [docs/sample-data-plan.md](../docs/sample-data-plan.md), 정답은 [answer-key.json](answer-key.json)에 있다.

## 구성

- 기관 6곳 × 항목 2종(임원연봉, 직원평균보수) = PDF 12개, 심은 오류 11개
- `exceptions/`: 예외 상황 테스트 파일

| 기관 | 심은 오류 수 |
|---|---|
| 한빛에너지공사 | 0 (오탐 확인용 대조군) |
| 푸른물관리공단 | 1 |
| 미래철도공사 | 1 |
| 바른주택공사 | 2 |
| 누리항공공사 | 3 |
| 가온에너지공단 | 4 |

정답 순위: 가온에너지공단 > 누리항공공사 > 바른주택공사 > 푸른물관리공단 = 미래철도공사 > 한빛에너지공사. 정답 상위 3곳은 가온, 누리, 바른이다.

## 예외 테스트 (exceptions/)

| 파일 또는 구성 | 앱이 보여야 할 것 |
|---|---|
| `스캔본_임원연봉.pdf` (이미지만 있고 글자 없음) | "글자를 읽을 수 없음"으로 처리 불가 |
| `가온에너지공단_임원연봉(복사).pdf` | 원본(`samples/가온에너지공단_임원연봉.pdf`)과 **둘 다** "중복", 고르기 전에는 순위에서 제외 |
| `이름없음_임원연봉.pdf` (기관명 없음) | "기관 미확인" |
| 한빛에너지공사 임원연봉만 올리고 직원평균보수는 올리지 않음 | 직원 평균보수 "업로드되지 않음" (미제출이라고 단정하지 않음) |
| `20MB초과_임원연봉.pdf` | 그 파일만 처리 불가, 나머지는 계속 점검 |

`20MB초과_임원연봉.pdf`는 용량이 커서 저장소에 넣지 않았다. 필요할 때 만든다.

## 다시 만들기

```bash
python scripts/make_samples.py              # 12개 + 예외 3개 + 정답지
python scripts/make_samples.py --with-big   # 20MB 초과 파일(약 21MB)도 만든다
```

필요한 것: `pip install pymupdf fonttools`, Windows 한글 글꼴(맑은 고딕). 만들 때 "문서에서 빠진 항목이 심은 오류와 일치하는지"를 스스로 검사하고, 어긋나면 오류로 끝난다.

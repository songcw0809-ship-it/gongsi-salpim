# 시연용 샘플 데이터 설계

PRD 3번(성공 기준)의 탐지율·오탐률·우선순위 정확도를 재기 위한 **정답지**다. 모든 기관과 수치는 직접 만든 가짜이며, 실제 기관과 무관하다.

기준 출처: 「공공기관의 통합공시에 관한 기준」(2025.12.30 개정) 별표 1 중 10번 임원연봉, 11번 직원 평균보수, 제3조(5년 자료 원칙).

## 1. 내장 체크리스트 (앱이 점검에 쓰는 기준)

### 10. 임원연봉 (연 1회, 4월말 공시 / 연도말 결산기준, 당해연도는 예산기준)
| 번호 | 점검 기준 |
|---|---|
| R10-1 | 임원별 기본급(기본연봉)이 있는가 |
| R10-2 | 항목별 수당이 있는가 |
| R10-3 | 급여성 복리후생비가 있는가 |
| R10-4 | 경영평가 성과급이 있는가 |
| R10-5 | 기타 성과상여금이 있는가 |
| R10-6 | 임원의 성별 평균보수가 있는가 |
| R10-7 | 기준 시점이 연도말 결산기준(당해연도는 예산기준)으로 표시되어 있는가 |

### 11. 직원 평균보수 (연 1회, 4월말 공시)
| 번호 | 점검 기준 |
|---|---|
| R11-1 | 직원 1인당 기본급, 항목별 수당, 경영평가 성과급, 기타 성과상여금이 있는가 |
| R11-2 | 직원 1인당 평균 보수가 남성·여성으로 구분되어 있는가 |
| R11-3 | 직원 평균근속연수가 남성·여성으로 구분되어 있는가 |
| R11-4 | 신입직원 평균보수가 있는가 |

### 공통
| 번호 | 점검 기준 |
|---|---|
| C-1 | 최근 5년 자료를 공시했는가 (자료가 없으면 그 사유를 적었는가) — 제3조 |
| C-2 | 공시 시점이 갱신 주기(4월말)를 지켰는가 — 제6조 |

## 3. 정답 순위 (우선순위 정확도 검증용)

기관6(4) > 기관5(3) > 기관4(2) > 기관2 = 기관3(1) > 기관1(0)

- 정답 상위 3곳은 **기관6, 기관5, 기관4**이다. 앱의 상위 3곳 중 2곳 이상이 이 안에 들면 목표를 달성한 것이다.
- 기관1은 오류가 하나도 없는 대조군이다. 여기서 지적이 나오면 모두 오탐으로 센다.

## 4. 예외 상황 테스트 파일 (12개와 별도, 집계에 넣지 않음)

PRD 5번 M1·M2의 규칙이 지켜지는지 보는 용도다.

| 파일 | 확인할 규칙 |
|---|---|
| 스캔본(이미지) PDF 1개 | "글자를 읽을 수 없음"으로 처리 불가 표시 |
| 기관6 임원연봉을 한 번 더 복사한 파일 | "중복"으로 표시하고 담당자가 고르게 함 |
| 기관명이 없는 파일 | "기관 미확인"으로 표시하고 추측하지 않음 |
| 기관1 임원연봉만 있고 직원 평균보수가 없는 경우 | "업로드되지 않음"으로 표시하고 미제출이라고 단정하지 않음 |
| 4MB 초과 파일 | 그 파일만 "처리 불가"로 표시하고 나머지는 계속 점검 |
